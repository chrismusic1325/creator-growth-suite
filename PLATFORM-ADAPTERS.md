## Capability truth rule

A platform name in configuration is not considered an operational
capability.

`python platform-status.py` is the source of truth.

A capability is TRUE only when executable code for that capability
exists and its prerequisites are available.

Browser-login profiles count only as connections. They do not count
as optimization/publishing capability by themselves.
