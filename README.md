# Creator Growth Suite

Creator growth automation tools and campaign operations.

## What's Inside

This repository contains the creator-growth automation toolkit:

- **Campaign Operations** — Launch, modify, execute, and report on authorized creator-growth campaigns with verifiable external actions and recurring-job state management.
- **Preflight Audit** — Audit a creator-growth system before launch: verify reusable assets, operable capabilities, metric baselines, cost constraints, and the campaign start gate.

## Source

These skills are maintained in the OpenClaw workspace:

- `creator-campaign-operations` — Campaign launch/execution/reporting operations
- `creator-growth-preflight` — Pre-launch audit and verification

## Usage

These are skill definitions used by OpenClaw agents. See the OpenClaw workspace at `~/.openclaw/workspace/` for the agent configuration that uses these skills.

## Cost

$0 — all operations use free-tier APIs and legitimate permitted outreach only.

## Authentication

Platform authentication (YouTube, Bandcamp, Rumble, etc.) is handled by the OpenClaw agent environment. See `~/.openclaw/openclaw.json` for configured auth profiles.
